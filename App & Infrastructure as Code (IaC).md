## Tools
- ARM templates

### Azure Resource Manager templates
- defines infrastructure and configuration for deployment
- submitted to Azure Resource Manager and deployed parallelly
- `WhatIf` allows to preview deployment
- can be integrated into multiple CI/CD pipelines
- formats
	- JSON
	- Bicep

### Azure Bicep templates
- domain specific language 
- can be used to create ARM templates
- native to azure ecosystem
- can use Bicep CLI to decompile any template into Bicep
