### Question 1

You are designing an identity solution for a company that is migrating to Azure. The company has the following requirements:
- **Users must authenticate using their existing on-premises Active Directory credentials.**
- **Password hash synchronization is not permitted due to regulatory compliance.**
- **If the on-premises environment becomes unavailable, users must still be able to authenticate to cloud-only applications.**

**What should you recommend?**

A) Microsoft Entra Connect with password hash synchronization as a backup  
B) Microsoft Entra Connect with pass-through authentication and password hash synchronization enabled as a backup  
C) Microsoft Entra Connect with federation using AD FS and password hash synchronization enabled as a backup  
D) Microsoft Entra Connect with pass-through authentication only

> [!faq]- Show Answer & Explanation
> **Answer: C** — Federation with AD FS keeps password hashes on-premises for primary authentication, satisfying the compliance requirement. Enabling password hash sync as a **backup** (not primary) ensures cloud authentication remains available during an on-premises outage. Pass-through authentication (D) would fail entirely if on-premises is unavailable, and (B) uses PTA as primary which also fails during outages without PHS backup, but the requirement explicitly states PHS is not permitted as a primary method — however as a disaster recovery fallback it's a separate consideration. AD FS with PHS backup is the Microsoft-recommended resilient architecture.
